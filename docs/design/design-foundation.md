# 디자인 파운데이션 — GATE v3.1 · 한국식 × iOS 위젯, 플랫 (2026-08-28)

**한국어** | [English](design-foundation.en.md)

> 2단계(웹)·5단계(앱) 화면의 기준 문서. 목업·프로토타입 아티팩트("Ticket Rush GATE")와 항상 함께 갱신한다.
> 원칙: 여기 없는 색·폰트·그림자·모서리값을 화면 코드에 새로 만들지 않는다.
> 이력: v1 웨이파인딩 사이니지(서구 어워드풍이라 폐기) → v2 한국식 → **v3 한국식 정보 구조에 iOS 위젯 톤의 프리미엄 표면**.

## 1. 컨셉 — "한국 티켓팅 문법 × iOS 위젯 표면"

정보 구조(무엇이 어디에 있는가)는 **인터파크 계열 티켓팅**을 그대로 따르고,
표면(어떻게 보이는가)은 **iOS 위젯·월렛 문법**으로 올린다. 은유가 곧 컴포넌트다:

- 오픈 카운트다운 = **잠금화면 다크 위젯** (플랫 다크 카드 + 대형 숫자, 임박 시 숫자가 레드로)
- 대기열 = **액티비티 링** (브랜드 단색 스트로크 원형 게이지 안에 순번)
- 좌석 선점 타이머 = **다이나믹 아일랜드형 캡슐** (상단 플로팅 다크 필, 레드 펄스 도트 + 남은 시간)
- 예매 완료 티켓 = **Apple Wallet 패스** (다크 헤더 + 필드 그리드 + 절취선 + 바코드)
- 상단 바·하단 CTA 바·탭바 = **프로스티드 글래스** (blur 18px + saturate 1.6)

한국식 뼈대는 유지: `‹ 뒤로` 헤더, 하단 탭바, 회차 선택 셀, 유의사항 아코디언,
예매수수료 분리, 결제수단 라디오, 전체 동의, 회색 안내박스, 잔여석 표기.

### 금지 목록 (AI 냄새 + 톤 이탈)

- Inter / Roboto / Space Grotesk, 이모지 아이콘, 크림+세리프+테라코타, 근검정+형광 원포인트
- 라틴 대문자 장식 라벨(SINGLE NIGHT, ADMIT ONE 류), 브루탈리즘 헤어라인
- **그라디언트·글로우 배경 전면 금지** (v3.1) — 깊이는 단색 면 + 그림자로만. 블러는 프로스티드 바 3곳만
- 플랫한 1px 테두리 카드 — 그림자가 면을 만든다

## 2. 토큰

### 2-1. 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#F2F3F7` | 그라운드 (iOS grouped background) |
| `--surface` | `#FFFFFF` | 카드 |
| `--glass` | `rgba(255,255,255,.72)` + `backdrop-blur(18px) saturate(1.6)` | 상단 바·CTA 바·탭바 |
| `--ink` | `#16181D` / `--sub` `#8A8F98` | 본문 / 보조 |
| `--line` | `rgba(60,60,67,.12)` | 헤어라인 (카드 내부 행 구분만) |
| `--brand` | `#2E5BFF` (CTA·좌석·링 전부 단색) | 액션·내 좌석·링 |
| `--danger` | `#FF453A` (iOS red) | 선점 타이머·D-day·긴급 |
| widget-dark | `#14161B` 플랫 | 카운트다운·포스터·월렛 헤더·메인 배너 |

좌석: 선택 가능 `#D6E1FF`, 내 선택 = brand 그라디언트 + 링 섀도, 선점·판매완료 `rgba(60,60,67,.12)`, 판매불가 투명.

### 2-2. 타이포그래피

- 전 화면 **Pretendard**(SF에 맞춰 설계된 한글 서체 — iOS 톤의 근거) → Noto Sans KR 폴백. 별도 디스플레이 서체 없음.
- 무게 위계 800/700/600/500/400. 큰 숫자(카운트다운 52px, 순번 40px)는 자간 -0.02em + `tabular-nums`.
- IBM Plex Mono는 예매번호·바코드 캡션만.

### 2-3. 면·그림자·모서리 — "그림자가 면을 만든다"

- 라운드: 카드 **22px**(스쿼클 톤), 배너·패스 24px, 버튼 18px, 셀 14px, 좌석 6px, 캡슐·뱃지 pill.
- 카드 그림자(2겹 고정): `0 1px 2px rgba(16,19,25,.04), 0 10px 28px rgba(16,19,25,.09)`.
- CTA 그림자: 브랜드 컬러 섀도 `0 6px 16px rgba(46,91,255,.24)`. 그라디언트·인셋 하이라이트 없음.
- 카드에 외곽 테두리 없음. 구분선은 카드 내부 행에만.
- 폰 프레임·목업은 뷰포트에 맞춰 스케일(`min(820px, 100vh - 180px)`) — 페이지 스크롤 없이 한 화면에 fit.

### 2-4. 모션

- 이징 둘: 표준 `cubic-bezier(.16,1,.3,1)`, 스프링 `cubic-bezier(.34,1.4,.44,1)` (버튼·아일랜드·체크 팝).
- 버튼 피드백 `scale(.97)`, 좌석 탭 `scale(.85)`, 아일랜드 등장 = 위에서 스프링 슬라이드.
- 화면당 큰 연출 하나: 카운트다운 위젯 / 링 진행 / 좌석 소등 / 체크 팝. `prefers-reduced-motion` 존중.

## 3. 화면별 구성 (목업·프로토타입에 구현됨)

1. **목록** — iOS 라지 타이틀 "지금 예매", 다크 위젯 메인 배너(글로우 아트), 오픈 예정 리스트(알림 받기 필 버튼), 프로스티드 탭바, 상태바(9:41)
2. **상세** — 포스터(다크 위젯 미니) + 정보, 회차 셀(체크 원), **잠금화면형 카운트다운 위젯**, 유의사항 아코디언
3. **대기열** — **액티비티 링** 카드(순번·게이지·통계 필), 안내박스, 입장 플래시
4. **좌석 선택** — iOS 세그먼트(A/B/C/D), STAGE 필, 좌석 그리드 카드(경쟁자 잠식), 프로스티드 선택 바, 선점 시 **아일랜드 타이머** 등장
5. **결제** — 주문 정보 카드(수수료 분리), 결제수단(iOS 라디오), 전체 동의 + **iOS 스위치**(실패 시뮬), 총액 강조, 그라디언트 CTA
6. **완료** — 체크 팝 + **월렛 패스**(다크 헤더·필드 그리드·절취선·바코드)

에러: 사용자 문구 + 개발 코드 병기 — `SEAT_ALREADY_HELD`, `HOLD_EXPIRED`, `PAYMENT_DECLINED`.

## 4. 2단계 구현 가이드

- 토큰 Tailwind 1:1 매핑(`bg/surface/glass/ink/sub/line/brand/danger`), 임의 값 금지.
- Pretendard 서브셋 + `next/font`. `backdrop-filter`는 상단/하단 바 3곳만 (저사양 폰 부하 주의 — 4단계 Lighthouse로 검증).
- 좌석맵은 Canvas — DOM 그리드는 시연용. 셀 규격(정사각·라운드 6px·간격 5px)과 상태 색만 가져간다.
- 링·아일랜드·글로우는 CSS/SVG로만. 모션 라이브러리 추가 금지(ARCHITECTURE 4-1 목록 밖).
