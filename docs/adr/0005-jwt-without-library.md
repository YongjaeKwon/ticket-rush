# 0005. 입장 JWT — 라이브러리 없이 JDK 암호화로 직접 구현 (1단계)
날짜: 2026-08-31 · 단계: 1 · 상태: 결정

## 문맥
대기열 입장권은 HS256 JWT다. 스택 목록(ARCHITECTURE 4-1)에 JWT 라이브러리가 없고, 목록 밖 라이브러리는 추가 전에 물어야 한다.

## 선택지
- **JDK 내장(Mac + Base64)으로 직접 구현**: 의존성 0, 약 40줄. HS256 하나만 필요해서 충분. 서명·만료 검증 로직이 눈에 다 보여 학습에 좋음. 단점: 표준 클레임 검증·키 회전 같은 건 없음.
- jjwt 등 라이브러리: 검증된 구현, 실무 표준. 단점: 이 프로젝트가 쓰는 건 sign/verify 두 함수뿐인데 의존성이 하나 늘고, 규칙상 사람 승인 필요.

## 결정
직접 구현. 필요한 표면적이 작고(발급 1곳, 검증 1곳), 상수 시간 비교(MessageDigest.isEqual)와 만료 검사만 지키면 위험도 작다.

## 결과
얻는 것: 의존성 0, JWT 구조 학습. 잃는 것: 라이브러리의 방어적 검증 → shared/token/HmacJwt 한 파일에 격리해 교체 지점을 좁힘. 다시 볼 조건: 3단계 서비스 분리로 토큰 사용처가 늘면 jjwt로 교체.
