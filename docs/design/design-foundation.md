# 디자인 파운데이션 — GATE-1 (v0.1, 2026-08-28)

> 2단계(웹)·5단계(앱) 화면의 기준 문서. 목업·프로토타입 아티팩트("Ticket Rush GATE-1")와 항상 함께 갱신한다.
> 원칙: 여기 없는 색·폰트·그림자·모서리값을 화면 코드에 새로 만들지 않는다.

## 1. 컨셉 — "공연장 사이니지"

선착순 티켓팅의 정서는 **대기 → 입장 → 확정**이다. 이건 공항·역·공연장의 안내판 경험과 같다.
그래서 UI 언어를 공연장 **웨이파인딩 사이니지**(콘크리트 벽, 코발트 안내판, 게이트 넘버링)와
**출발 안내판**(스플릿 플랩 보드)에서 가져온다. 장식이 아니라 은유가 기능이다:

- 오픈 카운트다운 = 출발 시각 플립 보드
- 대기열 순번 = 게이트 대기 번호판
- 좌석맵 = 소등된 객석(이 화면만 다크 반전 — 의도된 연출)
- 예매 확정 = 개찰 도장이 찍힌 티켓 스텁

### AI 냄새 제거 체크리스트 (금지 목록)

- Inter / Roboto / Space Grotesk, 보라→파랑 그라디언트, 글래스모피즘
- 크림 배경 + 세리프 디스플레이 + 테라코타 액센트 조합
- `rounded-lg`(8~16px) 카드 남발, 라운드 카드 위 액센트 색 세로 바
- 그림자 여러 겹(soft shadow stack), 이모지 아이콘, 전부 가운데 정렬
- 목적 없는 넘버링·구분선. (플로우 스텝 1~6 넘버링은 실제 순서이므로 유지)

| 계열 | 사이트 | 가져온 패턴 (그대로 복사 아님 — 원리만) |

## 3. 토큰

### 3-1. 색 — 라이트(사이니지) 기본, 좌석맵만 다크(소등) 고정

| 토큰 | 값 | 용도 |
|---|---|---|
| `--concrete` | `#EAEBE7` | 페이지 그라운드 (순백 아님 — 쿨 콘크리트) |
| `--paper` | `#F7F8F5` | 카드·시트 서피스 |
| `--steel-900` | `#16181B` | 본문 잉크, 채워진 좌석(남의 확정) |
| `--steel-600` | `#4A4F55` | 보조 텍스트 |
| `--hairline` | `rgba(22,24,27,.14)` | 모든 구분선 (1px) |
| `--cobalt` | `#0B45D0` | 액센트 하나: CTA, 내 선택, 확정 도장 |
| `--cobalt-press` | `#08339B` | pressed |
| `--signal` | `#FF5A1F` | 긴급 전용: 홀드 타이머, 임박 카운트다운. 텍스트는 `#D93A00` |
| 다크(좌석맵) | bg `#0E1013` / surface `#16191D` / text `#E8EAE6` / cobalt `#5B8CFF` / signal `#FF6B35` | 소등 연출 |

좌석 상태(비트맵 2비트와 1:1): 빈자리 = 아웃라인, 홀드 = signal 채움, 확정 = steel 채움, 판매불가 = 해치(사선), 내 선택 = cobalt.
시맨틱(오류·경고)은 signal 계열을 쓰되 액센트(cobalt)와 역할을 섞지 않는다.

### 3-2. 타이포그래피

| 역할 | 폰트 | 비고 |
|---|---|---|
| 디스플레이·숫자·라틴 라벨 | **Archivo** (variable: wght·wdth) | 웨이파인딩 그로테스크. 헤드라인 wdth 110+/wght 800, 라벨 wdth 75/자간 +0.08em/대문자 |
| 한글 본문 | **Pretendard**(1순위, 2단계에서 서브셋 self-host) → IBM Plex Sans KR(웹폰트 폴백) | 본문 15px/행간 1.6 |
| 데이터·코드 | **IBM Plex Mono** | 순번·가격·시각·좌석번호. 반드시 `tabular-nums` |

스케일: 12 / 13 / 15 / 18 / 24 / 34 / 56 / 96(플립 숫자). 헤드라인 `text-wrap: balance`.

### 3-3. 면·선·그림자·모서리

- 선이 구조를 만든다: 구분은 전부 `1px --hairline`. 사이니지 판은 상단 `3px --steel-900` 보더.
- 그림자 기본 0. 예외 둘 — 바텀시트 `0 -1px hairline` + 딤(오버레이 `rgba(14,16,19,.55)`), CTA 눌림은 그림자 대신 `translateY(1px)`.
- 모서리: 기본 `2px`(판금), 상태 칩만 pill. 8px 이상 금지.
- 티켓 절취선: `1px dashed hairline` + 양끝 반원 펀치.

### 3-4. 모션

- 이징 하나: `--ease: cubic-bezier(.16, 1, .3, 1)` (expo-out). 지속 120 / 240 / 480ms.
- 큰 연출은 화면당 하나만: 상세 = 스플릿 플랩, 대기열 = 순번 롤링, 좌석맵 = 좌석 점등, 완료 = 확정 스탬프.
- `prefers-reduced-motion: reduce` 시 플립·롤링은 즉시 값 교체.

## 4. 화면별 적용 (목업·프로토타입에 구현됨)

1. **목록** — 타이포 포스터 카드(이미지 없이 코발트 판 + 대형 타이포), 오픈 D-day 칩
2. **상세** — 회차 정보 hairline 테이블 + 스플릿 플랩 카운트다운, CTA 하단 고정
3. **대기열** — 게이트 사이니지 + 순번 대형 롤링 숫자, 진행 스트라이프, 입장 시 플래시
4. **좌석맵** — 다크 반전. 무대·구역 미니맵 → 좌석 그리드, 가상 경쟁자 점등(홀드 잠식), 탭 → 바텀시트 → 홀드 5:00 타이머(signal)
5. **결제** — 주문 요약 mono 테이블, mock 카드 폼, 홀드 타이머 유지, 실패 시뮬 토글
6. **완료** — 티켓 스텁 + CSS 바코드 + CONFIRMED 스탬프 애니메이션

## 5. 2단계 구현 가이드

- 토큰은 Tailwind theme로 1:1 매핑(`concrete/paper/steel/cobalt/signal`), 임의 값(`text-[#...]`) 금지.
- Pretendard 서브셋 + `next/font`, Archivo·Plex Mono는 라틴 서브셋만.
- 좌석맵은 Canvas — 프로토타입의 DOM 그리드는 시연용이며 상태 색·크기 규격만 가져간다 (좌석 셀 26×26, 간격 6, 통로 14).
- 애니메이션은 CSS 우선, JS는 숫자 롤링만. Framer Motion 등 라이브러리 추가 금지(4-1 목록 밖).
