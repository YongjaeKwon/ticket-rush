# 0002. Spring Boot 4.0 + Modulith 2.0 (3.5/1.4 대신)
날짜: 2026-08-28 · 단계: 1 · 상태: 결정

## 문맥
ARCHITECTURE 4-1은 "Spring Boot 최신 안정판, 버전은 ADR에 기록". 후보는 Boot 3.5 + Modulith 1.4(자료 많음)와 Boot 4.0 + Modulith 2.0(최신 안정).

## 선택지
- **Boot 4.0.3 + Modulith 2.0.5**: 현재 안정판 조합(Modulith 2.0은 Boot 4.0 대상으로 컴파일). 프로젝트 수명 내 3.x EOL 걱정 없음. 단점: 자료가 아직 3.x 위주, 스타터 개편(web → webmvc, Flyway 모듈 분리) 학습 필요.
- Boot 3.5 + Modulith 1.4: 자료 풍부. 단점: 신규 시작치고 구세대, 나중에 4.x 마이그레이션 비용.

## 결정
Boot 4.0.3 + Modulith 2.0.5. 신규 프로젝트는 최신 안정판에서 시작하는 게 총비용이 낮고, 개편된 스타터 구조 자체가 학습 포인트.

## 결과
얻는 것: 최신 안정 조합, 마이그레이션 부채 없음. 잃는 것: 검색 자료 부족 → context7로 공식 문서 확인으로 보완. 다시 볼 조건: 의존 라이브러리(springdoc 등)가 Boot 4 미지원이면.
