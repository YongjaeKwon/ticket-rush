# 디자인 파운데이션 — GATE v2 · 한국식 (2026-08-28)

> 2단계(웹)·5단계(앱) 화면의 기준 문서. 목업·프로토타입 아티팩트("Ticket Rush GATE")와 항상 함께 갱신한다.
> 원칙: 여기 없는 색·폰트·그림자·모서리값을 화면 코드에 새로 만들지 않는다.
> v1(웨이파인딩 사이니지·스플릿 플랩)은 "너무 서구 어워드풍"이라는 피드백으로 폐기하고,
> **한국 티켓팅 앱 문법**으로 전면 개편했다.

## 1. 컨셉 — "한국 사용자가 이미 아는 티켓팅"

정보 구조는 **인터파크 계열 티켓팅**을, 비주얼은 **국내 앱 표준 문법**(토스·29CM 계열의
흰 카드 + 미묘한 그림자 + 무게 위계 타이포)을 따른다. 새로 배울 것이 없는 화면이 목표.

- 상단 `‹ 뒤로` 헤더, 목록 화면 하단 탭바(홈 / 내 티켓 / MY)
- 회차 선택 셀, 잔여석 표기, 예매 유의사항 아코디언, 예매수수료 분리 표기
- 대기열 = "나의 대기 순서 N번째" 카드 + 게이지 + 회색 안내박스
- 좌석맵 = 라이트 배경(국내 좌석맵 표준), 선택 가능 좌석이 색으로 활성
- 결제 = 결제 수단 라디오(카드/카카오페이/네이버페이) + 전체 동의 + 총액 강조
- 완료 = 체크 아이콘 + 모바일 티켓 카드(절취선·바코드)

### AI 냄새 + 서구 어워드풍 금지 목록

- Inter / Roboto / Space Grotesk, 보라→파랑 그라디언트, 글래스모피즘, 이모지 아이콘
- 라틴 대문자 디스플레이 타이포, 브루탈리즘 hairline 격자, 스플릿 플랩 등 "장치"가 앞서는 연출
- 크림 배경 + 세리프 + 테라코타, 근검정 + 형광 원포인트
- 소프트 섀도 스택(카드당 그림자 1개, 얕게), 목적 없는 넘버링

## 3. 토큰

### 3-1. 색 — 라이트 기본 (다크는 2단계에서 토큰만 교체)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg` | `#F4F6F8` | 페이지 그라운드 (쿨 그레이) |
| `--surface` | `#FFFFFF` | 카드·시트·헤더 |
| `--ink` | `#191F28` | 본문 |
| `--sub` | `#6B7684` | 보조 텍스트 |
| `--line` | `#E5E8EB` | 구분선·비활성 |
| `--brand` | `#335CFF` | 브랜드 블루 하나: CTA, 내 선택 좌석, 링크 |
| `--brand-press` | `#2749D6` | pressed |
| `--danger` | `#F04452` / bg `#FDEBEC` | 긴급 전용: 선점 타이머, D-day, 총액 강조 |

좌석 상태(비트맵 2비트와 1:1): 선택 가능 = 연블루 `#CFDCFF` 채움, 내 선택 = brand,
선점·판매완료 = `#E5E8EB`, 판매불가 = 투명. **선택 가능한 것이 색을 갖는다**(국내 좌석맵 문법).

### 3-2. 타이포그래피

| 역할 | 폰트 | 비고 |
|---|---|---|
| 전 화면 | **Pretendard**(1순위, 2단계 서브셋 self-host) → Noto Sans KR(웹폰트 폴백) | 별도 디스플레이 서체 없음 — **무게(800/700/500/400)와 크기로만 위계** |
| 숫자 | 동일 + `tabular-nums` | 순번·금액·카운트다운·잔여석 |
| 코드성 데이터 | IBM Plex Mono | 예매번호·바코드 캡션만 |

스케일: 11 / 12 / 13 / 14 / 15 / 17 / 20 / 24 / 56(대기 순번). 자간은 큰 글자에만 -0.01~-0.02em.

### 3-3. 면·선·그림자·모서리

- 카드 라운드 **16px**, 버튼 **14px**, 입력·셀 12px, 뱃지 6px, 칩·게이지 pill.
- 그림자는 카드당 1개: `0 1px 3px rgba(25,31,40,.05)`. 그 외 금지.
- 구분선 `1px #E5E8EB`. 회색 안내박스(`#F2F4F6`, 12px 라운드)가 국내 문법의 핵심 부품.
- 티켓 절취선: `2px dashed` + 양끝 펀치 홀.

### 3-4. 모션

- 이징 하나: `cubic-bezier(.16,1,.3,1)`, 지속 120 / 240 / 450ms.
- 화면당 큰 연출 하나: 상세 = 초 단위 카운트다운(임박 시 danger 반전), 대기열 = 게이지 진행,
  좌석 = 선점 시 좌석 소등, 완료 = 체크 아이콘 팝.
- 버튼 피드백은 `scale(.985)`. `prefers-reduced-motion` 존중.

## 4. 화면별 구성 (목업·프로토타입에 구현됨)

1. **목록** — 메인 배너(포스터 아트 + 오픈 일시 + D-day 뱃지), 오픈 예정 리스트(오픈 알림 버튼), 탭바
2. **상세** — 포스터+정보 히어로(단독판매·1인 1매 뱃지), 회차 선택 셀, 오픈 카운트다운 카드, 유의사항 아코디언
3. **대기열** — 나의 대기 순서 카드(N번째·게이지·예상 시간), 안내박스, 입장 전환 플래시
4. **좌석 선택** — STAGE 바, 구역 탭, 좌석 그리드(가상 경쟁자 잠식), 하단 선택 바 → 선점 → 5:00 타이머
5. **결제** — 주문 정보(수수료 분리), 결제 수단 라디오, 전체 동의, 총액 danger 강조, 실패 시뮬
6. **완료** — 체크 팝 + 모바일 티켓(좌석·예매번호·바코드) + 안내박스

에러 문구는 사용자용 한국어 + 개발용 코드 병기: `SEAT_ALREADY_HELD`, `HOLD_EXPIRED`, `PAYMENT_DECLINED`.

## 5. 2단계 구현 가이드

- 토큰은 Tailwind theme로 1:1 매핑(`bg/surface/ink/sub/line/brand/danger`), 임의 값 금지.
- Pretendard 서브셋 + `next/font`. IBM Plex Mono는 예매번호 영역만 서브셋.
- 좌석맵은 Canvas — 프로토타입 DOM 그리드는 시연용. 상태 색·셀 규격(정사각, 라운드 5px, 간격 5px)만 가져간다.
- 애니메이션은 CSS 우선. 모션 라이브러리 추가 금지(ARCHITECTURE 4-1 목록 밖).
